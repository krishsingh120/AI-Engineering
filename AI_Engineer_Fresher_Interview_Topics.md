## 🎯 Interview Focus

For fresher-level AI Engineer interviews, focus heavily on **scenario-based problem solving** rather than memorizing framework APIs.

Think about every AI system through these dimensions:

> **Quality → Security → Reliability → Scale → Latency → Cost → Observability**

Be prepared to explain how your system behaves when:
- The LLM fails
- Retrieval returns irrelevant context
- The model hallucinates
- A user performs prompt injection
- Traffic suddenly increases
- LLM costs become too high
- A tool/API times out
- A dependency goes down
- Multiple users/tenants share the same system
- The model returns invalid structured output
